# feed-stats

Tracking the feed and platform presence over time.

```
rss.md         master feed + satellite status
cadence.md     publishing cadence — the silence risk
platforms.md   GBP, social, citation metrics
```

## Why this exists

The RSS Supercluster work needs a permanent home. Publishing cadence is
currently a known gap — silence for 90 days is worse than never having
published. A folder that nobody updates is a folder that doesn't help, so the
rule is: **update on the same day something ships**, not in a batch later.
