# Publishing Cadence

## The rule

**Master feed: weekly cadence. Silence for 90 days is worse than never having
published.**

A feed that goes quiet looks abandoned, and an abandoned feed is a negative
signal where a missing feed is merely neutral.

## Current state

rhythm. This must be fixed before the master feed is built — a feed pointed at
an irregularly-updated site just amplifies the irregularity.
