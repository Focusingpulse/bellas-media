# published

The finished versions of things that are live.

```
blog/     published posts, as published
pages/    published page copy snapshots
assets/   final approved images, by category
```

## Why keep copies

The live site changes. This folder is the record of what a page said on the
day it was signed off. That matters when someone asks "what did the About page
say in September?" — and it matters for entity work, where the exact wording
is the evidence.

## Assets

Only images that are **approved and in use**. Raw and unedited files live in
the private vault. If an image here came from a client's property, a consent
record must exist in the vault before it was moved here.
