# log

What shipped, and when. Newest at the top.

- **`site-changes.md`** — dated record of site work: what changed, where, and whether it's verified
- **`published-posts.md`** — the blog publishing record: what went live, where, when

## Why this exists

So the question "when did that change?" has an answer that isn't memory. Also
so Sandra and Dolman can read the record without asking Chris.

**Rule:** write the entry when it ships, not later. A log written afterwards
is a reconstruction, and reconstructions drift.
